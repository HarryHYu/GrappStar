# Architecture panel (reference only)

Four independent architects each designed the whole base from one lens on 3 Nov 2026 (planning only). Their
documents are kept here as reference: failure walks, interlocks, risks and measurement lists worth reading.
They are NOT binding. Binding: base/spec/BASE_SPEC.md, base/spec/params.py and base/spec/DECISIONS.md.

- `B_reliable.md`: reliability first (source of decisions D15, D16, D17).
- `C_compact.md`: compact and printable (source of D14; its sprag-on-the-rail-pin change was rejected, D13).
- `D_perform.md`: performance (independently found the take-up bus, D15; retrieve at negative pitch; reel shroud).
- `A_faithful.md`: added when it lands.
